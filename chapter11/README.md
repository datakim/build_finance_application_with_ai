# Chapter 11: Building the qualitative engine with news analysis and LLMs

*Financial AI in Practice: A Playbook for Credit, Fraud, and Investment Systems* · Part 4: Building AI for investment strategies

Chapter 11 builds the qualitative engine: it collects news from NewsAPI, World Nuclear News, Google News and GDELT, unifies the sources, embeds the articles with OpenAI, stores them in ChromaDB, and uses an LLM analyst with date-filtered retrieval to turn the news into a structured market view.

## How to run

1. Put `NEWS_API_KEY` and `OPENAI_API_KEY` in the repository's `.env` file (copy `.env.example`).
2. Run `Chapter11_news_ingestion.ipynb` first. It writes one Parquet file per source plus `news_ready_for_embedding.parquet`.
3. Then run `Chapter11_LLM_analyst.ipynb` from the same folder. Set `target_date` in the retrieval cell to a date inside the window your news covers.

## Differences from the printed book

- Listings 11.1 and 11.7 hard-code placeholder keys. The notebooks read the keys from `.env` instead, as appendix A.4 recommends.
- NewsAPI's free Developer plan returns articles from the last month only, with a 24-hour delay, so you won't get the book's articles.
- GDELT throttles rapid requests, and listing 11.4 waits 5 seconds per keyword. If every request is throttled, the notebook prints a message and returns an empty table with the expected columns, so the later cells still run. Wait a few minutes and rerun to get GDELT articles.
- Listing 11.5 (p. 303) reads timestamped file names. The notebook reads the names that the fetchers actually write.
- The "similarity" printed in listing 11.9 (p. 308) is 1 minus Chroma's squared L2 distance. For OpenAI's unit-length embeddings that equals 2 x cosine - 1, so it ranks results like cosine similarity but can be negative.
- `Chapter11_LLM_analyst.ipynb` adds the pandas and datetime imports it needs as a separate notebook.

### Look-ahead bias in LLM backtests

- Glasserman & Lin, "Assessing look-ahead bias in stock return predictions generated by GPT
  sentiment analysis" (2023). [arXiv:2309.17322](https://arxiv.org/abs/2309.17322) — when the backtest period overlaps
  the LLM's training data, results are biased two ways: the model may *know* what happened next
  (look-ahead), and its general knowledge of a famous company can *distract* it from the headline's
  actual sentiment. Surprisingly, within the training window, headlines with the company name removed
  performed *better* — distraction outweighed look-ahead. Run your news signals both ways.
- Xie et al., "FinBen: A holistic financial benchmark for large language models" (2024).
  [arXiv:2402.12659](https://arxiv.org/abs/2402.12659) — a broad benchmark for choosing a model for financial text tasks.
